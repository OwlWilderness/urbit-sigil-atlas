# Contributing

Track substantive work with a relevant GitHub issue. Reference the real issue number in each commit, including documentation commits.

Use issue-linked branches such as `feat/12-native-search`, `fix/13-slot-input`, or `docs/14-installation`. The repository's initial/default branch is `earth`.

Do not commit saved records, credentials, dependencies, generated ZIPs, workstation checkpoints or raw operational/browser evidence. Keep authentic glyph provenance and upstream license notices with the source.

The native Urbit port is a separate task described in `docs/urbit-native-port-prompt.md`; publishing this existing web app does not mean that port has been implemented or deployed.
